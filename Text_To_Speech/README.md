# Text to Speech 

The Text to Speech project is a web application built using HTML, CSS, and JavaScript. It provides a user-friendly interface for desktop users, allowing them to input text, including emojis, and have the device read it aloud in multiple languages.

## Features

- **Text Input**:
  - Users can type any text, including emojis, into the input box.
  - The text-to-speech engine processes the input and converts it to speech.
- **Multiple Language Support**:
  - Users can select from a variety of supported languages for speech output.
- **Desktop-Optimized Design**:
  - Designed with an attractive and intuitive user interface for desktop use.
- **Real-Time Feedback**:
  - The application provides immediate audio output when the "Speak" button is clicked.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
