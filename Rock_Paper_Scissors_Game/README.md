# Stone Paper Scissors 

The Stone Paper Scissors Game is a desktop-friendly web application built using HTML, CSS, and JavaScript. Users can play against the computer by selecting their move, while the computer randomly generates its choice. The results of each round are displayed below the game area.

## Features

- **Desktop-Optimized Design**: Designed specifically for desktop use with visually appealing graphics and layouts.
- **User vs. Computer Gameplay**:
  - Users can choose their move by clicking on corresponding images for Stone, Paper, or Scissors.
  - The computer generates its move randomly.
  - The result of each round (Win, Lose, or Draw) is displayed dynamically.
- **Interactive UI**: Features visually engaging designs and animations for a better gaming experience.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
