# Quiz App

The Quiz App is a responsive web application built using HTML, CSS, and JavaScript. It offers an engaging way to test knowledge with unlimited questions, dynamic feedback, and a vibrant color-coded interface for correct and incorrect answers.

## Features

- **Responsive Design**: Optimized for use on desktops, tablets, and mobile devices.
- **Unlimited Questions**: Supports an unlimited number of questions, making it versatile for various quizzes.
- **Dynamic Feedback**:
  - Displays a green highlight for correct answers.
  - Shows a red highlight for incorrect answers and reveals the correct answer.
- **Interactive UI**: Smooth transitions and a visually appealing color scheme enhance the user experience.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
