# Memory Game

The Memory Game is a responsive web application built using HTML, CSS, and JavaScript. The objective of the game is to find all pairs of matching cards. Once all pairs are matched, the game resets, shuffling the card positions to start a new round.

## Features

- **Responsive Design**: Optimized for use on desktops, tablets, and mobile devices.
- **Matching Game Mechanics**:
  - The game consists of a set of cards, each having a matching pair.
  - Players flip two cards at a time to find matching pairs.
  - If all pairs are matched, the game resets with shuffled card positions.
- **Randomized Card Positions**: The positions of the cards are shuffled at the start of each game to ensure a unique experience every time.
- **Interactive Gameplay**: Smooth animations and feedback for matched or unmatched pairs.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
