# Digital Clock

The Digital Clock is a web application built using HTML, CSS, and JavaScript. It displays the current time in real-time, updating every second. This application is designed for desktop use and features a clean and simple layout.

## Features

- **Real-Time Clock**: Displays the current time in hours, minutes, and seconds, updated every second.
- **Desktop-Optimized Design**: Tailored for desktop users with a clean and visually appealing layout.
- **Simple UI**: Focused on functionality with a straightforward design.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
