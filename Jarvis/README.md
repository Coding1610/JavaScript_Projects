# JARVIS - Virtual Assistant

JARVIS is a desktop-based virtual assistant built using HTML, CSS, and JavaScript. It provides a variety of useful features, including real-time greetings, the ability to open websites in new tabs, launching the device's calculator, and redirecting search queries to Google.

## Features

- **Real-time Greetings**:
  - Upon loading, JARVIS greets you based on the current time (morning, afternoon, or evening).
- **Open Websites**:
  - Users can ask JARVIS to open websites like Google, Instagram, YouTube, and more in new tabs.
- **Open Device Calculator**:
  - JARVIS can open the device's default calculator app when requested.
- **Google Search Redirect**:
  - Any general command or query is redirected to Google search results with the user's input.
- **Desktop-Optimized Design**:
  - The interface is designed to be user-friendly and works well on desktop devices.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **Development Tools**: Visual Studio Code
