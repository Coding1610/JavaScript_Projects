# Currency Converter

The Currency Converter is a web application built using HTML, CSS, and JavaScript. It allows users to convert currencies between various countries with accurate and up-to-date exchange rates. This application is designed for desktop use and features a user-friendly interface.

## Features

- **Desktop-Optimized Design**: Tailored for desktop users, ensuring a clear and functional layout.
- **Multiple Currency Support**: Includes most global currencies for conversion.
- **Accurate Exchange Rates**: Fetches real-time exchange rates using a reliable API.
- **Simple and Intuitive UI**: Easy to use, with clear input fields and conversion results.

## Tools and Technologies Used

- **Frontend**: HTML, CSS, JavaScript
- **API**: Currency exchange API for real-time data
- **Development Tools**: Visual Studio Code

## Project Setup

### Prerequisites
- A modern web browser to run the application.
- API key from a currency exchange service provider (e.g., ExchangeRate-API).
